Catalogue importer
Import a JSON array or CSV table using ra_deg + dec_deg or ra + dec coordinates in degrees. The manager can configure Name, Size by and Hue by after import.
Catalogue manager
Configure the catalogue name column and visual styling from the loaded metadata. Size by controls source radius, Hue by controls source hue, and Colour changes the catalogue base colour.
STCS importer
Import a JSON array or CSV table containing the STCS geometry in s_region. The manager can configure Name after import.
STCS manager
Manage astronomical observation footprints imported from STCS data. Name can be selected from the loaded metadata; each set can also be shown, hidden, removed, or assigned a colour.
